# Security policy

The latest published release is the supported version. Security fixes are released as updates; install them promptly.

Use GitHub's **Report a vulnerability** feature in the repository Security tab for a suspected vulnerability. If private reporting is unavailable, contact CloudTart through [cloudtart.com/contact](https://cloudtart.com/contact/) and ask for a secure reporting channel. Do not put vulnerability details, tokens, passwords, app secrets, private keys or customer records in a public issue.

Include a minimal reproduction, affected version, expected impact and sanitized diagnostics. Never send working production credentials. Public issues are appropriate for ordinary bugs after removing private information.

This software assumes a trusted administrator and an uncompromised server. Everyone with the management token controls all accounts in the installation. Follow the installation and operations guides for HTTPS, file permissions, backup retention and credential handling.
