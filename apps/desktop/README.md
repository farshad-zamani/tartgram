# TartGram web frontend

The React/Vite frontend lives in this directory under its existing workspace name `@app/desktop`. The current release is the server-hosted web panel at `/app/`.

Use the repository's [installation guide](../../docs/installation.md), [Meta guide](../../docs/meta-setup.md), and [Persian guide](../../docs/README.fa.md). Development API proxies point to localhost; production uses same-origin session authentication.

Desktop packaging is coming in a future release if the project receives enough stars and community interest. No installer is shipped now.
